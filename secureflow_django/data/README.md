`vulnerabilities.json` содержит небольшой локальный набор из десяти Maven advisory-записей. В него включены пять уязвимых зависимостей из учебного проекта `TBagirov/training`, а также контрольный advisory для проверки того, что безопасная версия не срабатывает.

Это не полная CVE-база. Неизвестная зависимость не считается доказанно безопасной только потому, что её нет в файле. Для более полного покрытия обновляйте базу из проверенного источника advisory и учитывайте экосистему, версии, транзитивные зависимости и условия применимости каждой уязвимости.
